# まわる（Mawaru） v0.8 — ちかく／はなれて交換できる交換日記
> 渡すたび、もっと仲良くなる。

iOS 17以降のSwiftUIアプリです。**従来のローカルデモ**と、Firebase接続時に使える**実際の共有日記**の2モードがあります。

## v0.8 ちかく・はなれて、2つの交換方法
- 「交換」タブを新設。「📮ちかくで交換」または「💌はなれて交換」を選べます。
- **近距離**: Apple MultipeerConnectivity（Wi-Fi/peer-to-peer Wi-Fi/Bluetooth）による端末間の直接通信。双方がアプリを開いて検出・接続・受信を承認し、その場で手渡しします。アカウント不要。暗号化は必須。**AirDrop本体のAPIではありません**。
- **近距離バトン制御**: 送信側は受信端末の確認が来るまで次のターンに進みません。日記帳ID・版数・投稿IDをチェックし、同じ投稿を二重で取り込みません。画像/シールのデータも日記と同時に渡します。
- **初回**: 1人目がグループを作って1ページ目を書き、近くのiPhoneに渡します。受取人は「次の人」として参加。次に会ったときにまた渡し合えます。
- **遠距離**: Firebase Authentication/Firestore/Storage/Functionsを使ってクラウドで招待・バトン・日記を同期（Firebaseプロジェクトの初期設定/デプロイが必要）。
- **グループ名をページに表示**: 固定の「まわる diary」を廃止。グループ名・ページ番号・日付・執筆者をノートに表示します。
- **書くお題**: 6種類の質問を編集画面に追加。ボタンを押すと本文へ挿入されます。
- 旧バージョンのローカル日記は体験モードとして読み込めます。

**注意**: 近くの端末の発見は厳密な距離計測ではなく、同じLANで発見できる端末も含みます。近距離とオンラインは別々の日記帳で、途中の自動切り替え・合流には非対応。転送中は両方の端末でアプリを開いてください。詳細は docs/EXCHANGE_MODES.md を参照。

## v0.7 ノートの位置合わせと標準フォント
- **編集画面と完成後のノートでまったく同じ文字入力/表示部品（UITextView）を使用**。タイトル・日付・本文の余白、本文の高さ計算、用紙の最小高さ（540pt）を共通化。これまでの「編集時はTextEditor、完成後はText」の異なるレイアウトにより、正規化座標のシールや写真がずれていた問題を修正。
- **長文もページが伸びる**：同一のUITextViewサイズ計算で編集と完成ページを表示。本文の行数だけで両画面のノート高さが変わらないようにしました。固定添付の旧形式写真はノートの外に表示し、キャンバス座標を動かしません。
- **設定画面に「いつものノート用紙／フォント／文字サイズ／インク／揃え」を追加**。新しい日記を作ると設定値が自動で入ります。既存の日記と下書きは勝手に変わりません。
- **各ページだけ文字を上書き**：「このページだけ文字を変更」を開くと4種類のフォントと文字設定を調整できます。初期状態は折りたたみで、毎回選び直す必要はありません。
- **完成プレビュー**：送る前に編集画面を完成表示へ切り替え、シールが本文に重なった位置を確認できます。
- **誤送信防止**：バトンを渡す前に確認します。
- **下書きの写真を保持**：別添の写真もUserDefaultsではなくアプリ保存領域に保存し、閉じてから再度開いても復元します。送信後に下書きのファイルを消去。
- **編集操作の改善**：シール長押しで位置や回転をリセット、シールのみ／写真のみの一括削除、本文・タイトルの文字数を表示して共有日記と同じ上限に統一。
- **データ整理**：端末データの削除で下書きや画像キャッシュも削除。既存の日記のJSONデータ構造とFirebaseの既存投稿APIは維持。

**注意**: v0.6以前に送信済みのページのシール座標を自動で推定して変更することはできません。旧ページは保存済みの相対位置で表示します。レイアウト改善は新しいページ／現在の下書きから有効です。スクリーン幅が大きく異なる端末では本文が折り返されるため、文字の特定位置への完全なピクセル単位の固定は今後の課題です。詳しい確認項目は [docs/LAYOUT_QA.md](docs/LAYOUT_QA.md)。

## v0.6 写真の切り抜きドラッグ＆ドロップ・手書きフォント
- 写真アプリで被写体を長押しして、切り抜き画像を「まわる」のノートへドラッグ＆ドロップ。ドロップした位置に配置されます。
- **透明な背景をそのまま再現**：コピーした被写体をPNGで保存し、写真シールには白い背景をつけません。ノート上の画像はドラッグ・ピンチ・回転・長押し調整ができます。
- 絵文字シールの白い丸背景を削除。ノートの文章の上にも余白にも貼れます。
- 日本語手書き風フォント4択：まる文字、よもぎ、クレー One、Zen クレナイド。文字のサイズ14〜30pt、4色インク、左／中央／右寄せにも対応。選択をページごとに保存・共有します。
- スライダーと色選択を使う文字編集パネルを追加。過去のページと下書きは従来通り表示されます。

### フォントのライセンスとビルド
Google Fontsに公開されている [Yomogi](https://github.com/google/fonts/tree/main/ofl/yomogi)、[Klee One](https://github.com/google/fonts/tree/main/ofl/kleeone)、[Zen Kurenaido](https://github.com/google/fonts/tree/main/ofl/zenkurenaido) を **SIL Open Font License 1.1** に従ってアプリに同梱します。GitHub Actionsは \`scripts/prepare-fonts.sh\` でTTF本体と各OFLライセンス文をGoogle Fontsからダウンロードし、その後にXcodeGenを実行します。フォントバイナリはGitHubリポジトリへコミットしません。Macでローカルビルドする場合は、先に \`bash scripts/prepare-fonts.sh\` を実行してください。

## v0.5 本物のノートみたいな編集画面
- **文字とシール・写真が同じページ上に重なる**：本文を入力する罫線入りノート上の好きな位置にシールや画像を配置できます。余白にも本文の上にも貼れます。
- **編集と閲覧が同じノートレイアウト**：ページを渡してもレイヤーの位置・回転・拡大率が維持されます。完成した日記の文字もノート上に表示します。
- **ゆるかわ・レトロな交換日記UI**：ピンク／ミント／ラベンダー／レモン、マスキングテープ、パンチ穴、丸いカード、ポップな案内。
- **画像ペースト機能を継続**：フォトライブラリやコピー＆ペースト画像は、従来どおりシールのように移動できます。
- **クラウド側も同じUI**：Firebase接続済みなら参加者に配置を同期します（クラウド接続とデプロイ自体はまだ必要です）。
- 古い日記／下書きのデータ形式は変更せず、v0.4との互換性を維持します。

## v0.4 写真・コピーした画像を貼る
- iPhoneでコピーした写真やPNG画像を「ペースト」で日記の紙に直接貼り付け
- 写真ライブラリから選択して貼り付け（ページあたり4枚まで、画像は自動縮小）
- 画像もドラッグ・ピンチ・回転で自由に配置、長押しで削除
- 透明PNGは透明なまま保存。画像の元ファイルを端末内のApplication Supportに保存し、下書きと完成ページの両方から参照
- 共有日記ではFirebase Storageにアップロードし、認証済みの参加者だけが閲覧可能。Cloud Functions側で画像の所有者と形式を照合してから投稿確定
- 写真だけのページも作成可能。既存のv0.1〜v0.3の日記との互換性あり

## v0.3 シールでデコレーション
- ローカル日記とFirebase共有日記の両方で、シール帳から好きなシールを貼れます
- ハート・リボン・くま・いちご・肉球など14種類 + マスキングテープ3種類
- ドラッグで移動、ピンチで拡大縮小、2本指で回転、長押しで剥がす
- クリーム・さくら・ミント・ラベンダーの4種類のノート用紙
- 1ページ最大24枚、下書きも保存。日記を渡す際は位置・大きさ・角度を保存して相手の端末で再現
- 過去の日記にはシールのレイアウトを保持。v0.1/0.2の日記は自動的に未装飾の紙で表示
- 共有日記のシールデータはCloud Functionsで検証してから原子的に保存します

## v0.2 の共有機能（サーバー接続後）
- Appleでサインイン（Firebase Authentication / nonce対策済み）
- 2〜5名の共有日記帳、24文字・1回限り・7日間の招待コード
- Cloud Firestore リアルタイム同期（参加者だけ閲覧可能）
- Cloud Functions トランザクションによるバトンの原子的な受け渡し、投稿重複防止
- 文字の日記と端末内の自動下書き。書き終えたら順番が次のユーザーへ進みます
- 日記帳の休止・再開（オーナーのみ）
- GitHub Actions: バックエンド単体テスト + Firebase 13対応Xcodeで未署名IPA作成

**重要:** Firebaseプロジェクトの作成・Apple認証の設定・デプロイはまだ済んでいません。GoogleService-Info.plistがなければ共有タブは案内画面になり、ローカルデモは引き続き動作します。**共有機能はバックエンド配備と認証設定が完了するまで使用できません。**

## 設定
[docs/FIREBASE_SETUP.md](docs/FIREBASE_SETUP.md) を参照。Cloud Functions利用にはFirebase Blazeの請求先設定が必要になる場合があります。
個人情報を含む交換日記を本番公開する前に、ルール検証・エミュレータ統合テスト・監査・アカウント削除・通報・ブロックなどを完成させてください。

## iOSビルド
公開リポジトリのGitHub Actions → **Build unsigned iOS IPA** でビルド。成功時のArtifactsから `Mawaru-unsigned-IPA` ZIPを取得できます。

IPAは**未署名**なので、そのまま端末へインストールできません。適切な証明書で署名してください。アプリ本体のBundle IDは仮の `jp.mawaru.diary` です。

ローカル開発: Xcode 26.2以降 + XcodeGen、`xcodegen generate`。設定ファイルは公開リポジトリへアップロードしないでください。
