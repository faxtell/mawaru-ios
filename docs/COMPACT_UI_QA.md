# v0.9 ホームアイコン・省スクロール UI の確認

- [ ] iPhoneのホーム画面とアプリライブラリに、ピンクとミントの交換日記のアイコンが表示される
- [ ] アプリアイコンに黒い四隅や不自然な余白が見えない
- [ ] 「交換する」を開いた直後の大きな「きょうのページ、誰にまわす？」バナーがない
- [ ] 「近くの人」「遠くの人」が画面の上半分に収まり、即座にタップできる
- [ ] 「近くの人」内で接続状況は1行表示。タップで展開でき、端末が見つかったら自動で開く
