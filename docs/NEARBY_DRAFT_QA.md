# v0.9.1 近距離交換の接続前下書き・お題機能チェック

## 近くの人
- [ ] 1台だけで「近くの人」→「日記帳を作る」を実行
- [ ] 「ふたりの交換日記」の画面のタイトル直下に「日記を書く」が見える
- [ ] 相手と接続しなくてもボタンから編集画面を開ける
- [ ] 本文、タイトル、画像、シール、手書きフォントを変更して「下書きを保存」をタップすると戻れる
- [ ] 相手と接続していない間は「次へ渡す」が表示されず、送信済み扱いにならない
- [ ] アプリを閉じて再度開き、タイトル・本文・シールが復元される
- [ ] 2台で近距離接続を許可し、日記帳の招待を相手が承認する
- [ ] 書いた下書きを開き、「次へ渡す」で相手を選択する
- [ ] 相手が受け取りを承認した後に初めて自分の番が終わる
- [ ] 相手の番では編集ボタンが出ない
- [ ] 通信切断→再接続→再送しても同じページが重複しない

## お題
- [ ] 「何を書こう？ きょうのお題」を展開すると4ジャンルが出る
- [ ] 「人生ハード」に「滞納したサービスは？」がある
- [ ] ジャンルを変えると候補が変わり、「別のお題を見せて」で次の3件が出る
- [ ] お題をタップすると本文に追加され、以前に書いた文章は消えない
- [ ] お題を閉じると編集画面がコンパクトになる

**注意**：GitHub ActionsでのiOSビルドはコンパイルの検証です。2台実機のBluetooth／ローカルネットワーク権限と交換の最終確認は別途必要です。
