# v0.8 近くの人・遠くの人で交換する

## 近くの人（2人・近距離通信のみ）

1. 2台のiPhoneに同じ「まわる」アプリを入れる。Wi‑FiとBluetoothを有効にする。
2. 両方で「交換する」→「近くの人」を開く。初回はローカルネットワークへのアクセスを許可する。
3. 片方が「近くでまわす日記帳を作る」を選び、グループ名、2人のニックネーム、表紙色を決める。
4. 「近くにいる端末」から相手の端末を選び、相手が接続リクエストを承認する。端末名は本人確認にならないので、相手の画面を確認する。
5. 作成者が「相手を日記帳に招待」を選ぶ。相手はグループ名を確認して「受け取ってノートに保存」を選ぶ。受領確認後、日記帳が2台で共有される。
6. 作成者が最初のページを書き、本文や写真をデコレーションする。「次へ渡す」で接続済みの相手を選ぶ。
7. 受取人がページを承認すると、両方のiPhoneに同じページが保存され、書く順番が次の人に移る。
8. 次の人も同じ操作で、会ったときに直接渡す。

**注意:** 暗号化されたMultipeerConnectivity通信を使います。AirDropそのものではありません。Wi‑Fi／Bluetoothで近距離の相手を発見する仕組みで、メートル単位の距離判定はありません。同じLAN上の相手が見つかることもあります。両方のアプリを開いて接続する必要があります。

### 送信トラブル
- 相手が受け取りを拒否した場合、バトンは進みません。下書きは残ります。
- 相手が保存した後に受領確認が失われた場合、送信側には「確認待ち」が残ります。再接続して**同じ端末へ再送**すると、受信側は重複登録せず再確認を返します。
- 未確認の送信内容は端末の保存領域に記録されます。アプリを閉じても再送できます。
- 日記帳の初回ペアリングは2人用です。端末変更・アプリ削除によるデータ復元、3人以上の近距離グループは未対応です。
- 画像はページごとに最大4枚、シールは最大24枚、転送パケットは最大8MBです。

## 遠くの人（オンライン・最大5人）

1. FIREBASE_SETUP.md に従ってFirebase設定をアプリに組み込み、Cloud Functions / Firestore Rules / Storage Rulesをデプロイする。
2. 「交換する」→「遠くの人」を開き、Appleでサインインする。
3. グループ名・ニックネーム・表紙を決めて日記帳を作成する。
4. 招待コードを発行し、友だちに伝える。相手はコードで参加する。
5. 自分の番になった人が日記を投稿すると、次のメンバーへバトンが進む。
6. グループ名を変更するときは、作成者が日記帳右上のメニューから「グループ名を変更」を選ぶ。すべてのページに反映される。

**注意:** 公開リポジトリにFirebase設定を含めていないため、配布した未設定のIPAではオンライン交換を利用できません。Cloud FunctionsのrenameNotebookもデプロイしてください。オンラインの通信はFirebase側で処理され、エンドツーエンド暗号化ではありません。

## 実機テストチェックリスト

- [ ] 2台のiPhoneで互いを発見し、接続許可が出る
- [ ] 初回のノート招待を受け取ると2台に同じグループ名が表示される
- [ ] 本文・シール・透明PNG写真が相手へ届く
- [ ] 受領確認後に書く順番が切り替わる
- [ ] 受信を拒否すると順番は進まず、下書きが残る
- [ ] 通信切断後、同じ端末へ再送してもページが二重登録されない
- [ ] ページを長く書いても穴・罫線・ヘッダー・シールの位置が不自然にならない
- [ ] 新規ページのフォントがユーザー設定から自動適用される
- [ ] Firebase接続済みならオンライン招待・投稿・グループ名変更が使える
- [ ] Firebase未設定ならオンラインが使えないことが明示される

**ビルド成功と2台実機での動作確認は別です。** 実機同士の通信、OSの権限ダイアログ、再接続、署名後の動作は未検証です。一般公開前に実機テストとセキュリティ監査を実施してください。
