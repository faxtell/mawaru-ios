# まわる v0.8 — 近くと遠く、2種類の交換方法

## 近くの人と交換（端末同士の直接通信）
Apple MultipeerConnectivityを使用。AirDrop風の操作ですがAirDropそのものではありません。

1. 双方のiPhoneにこのアプリを入れ、Wi-FiとBluetoothを有効にする。
2. 両方で「交換」→「ちかくで交換」を開く。初回はローカルネットワークの許可が必要です。
3. 最初の執筆者が「ちかくで交換する日記を作る」を選び、グループ名、2〜5人の順番、表紙を選ぶ。
4. 近くの端末を探して接続。受取人は接続リクエストを確認して承認する。端末名だけで本人を証明できないので、相手の画面で確認する。
5. 最初の端末が日記を書いて接続済みの相手に送信。受取人はグループ名、タイトル、担当名を確認して受け取る。
6. 受取確認が送信側に戻るとページが確定し、バトンが進む。次の担当が書けるようになる。
7. 以降、会ったときにアプリで端末を再接続し、次の担当へ手渡す。

### 注意事項
- 暗号化された近距離接続が必要で、遠隔での送信はできません。ただし距離を厳密に測る機能ではなく、同じLANで発見できる端末も含まれます。
- 1回最大約12MB、直近最大70ページの履歴と画像を転送。大容量の写真が多い場合は転送できないことがあります。
- 宛先端末に受け取ってもらうまで送信側はターンを進めません。切断後は元の下書きから再送してください。
- 新しく受け取るメンバーには受け取った時点から役割が固定され、別のメンバーを偽装して変更することはできないようにします。ただし相手の端末名は本人証明ではありません。
- バックグラウンドでの自動配信やプッシュ通知は非対応。両方の端末でアプリを開いてください。
- 近距離データはFirebaseへ自動アップロードしません。オンライン日記との自動切り替え・データ合流は未実装です。

## 遠くの人と交換（オンライン）
「交換」→「はなれて交換」を開きます。Firebase環境に接続済みならAppleでサインイン、招待コードで参加、クラウド同期・バトン受け渡しが利用できます。
**Firebase未設定のIPAではオンライン交換はまだ使用できません。** Firebase初期設定・関数デプロイは FIREBASE_SETUP.md を参照。E2EEではありません。

## 新しい日記ページ
固定の「まわる diary」をグループ名とページ番号に置き換えました。日付・執筆者・紙のカラー・手書きフォント・シール配置を共通レイアウトで再現します。簡単なお題6種類から本文に挿入できます。

## 実機テスト
- [ ] 2台のiPhoneが互いを発見し、双方で接続許可できる
- [ ] 受信を断ると送信側のバトンは進まない
- [ ] 受け取ると両方で順番が移る
- [ ] 同一投稿を再送しても二重登録されない
- [ ] PNGの切り抜きシールを含む本文と画像が届く
- [ ] 一度アプリを閉じても受け取ったページを復元できる
- [ ] 通信が途切れたとき下書きが消えず、再送できる
- [ ] 3〜5人の順番で実際に渡せる
- [ ] 過去のv0.7以前の日記が開ける
- [ ] ページ上にグループ名・ページ番号が正しく出る
- [ ] Firebaseが未設定なら遠距離交換が使えないと分かる

この版はソースとIPAのコンパイル確認対象です。2台の実機でのエンドツーエンド試験は未実施。正式なセキュリティ監査、権限制御、障害時のリカバリーなどは公開前に強化してください。
