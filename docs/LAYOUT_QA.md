# v0.7 交換日記レイアウトの実機確認チェックリスト

GitHub ActionsはiOS向けのSwiftUIコンパイルおよびバックエンド単体テストを実行します。
**実機での座標比較テストは自動化されていません。** 以下を実施してください。

## 編集と完成画面の位置比較
1. 新しいローカル日記を作成し、「今日のタイトル」と本文を入力する
2. 本文の1行目、3行目、10行目、右側の余白へ、それぞれ異なるシールを置く
3. 切り抜いたPNG画像を文字の上に1枚置いて、傾きと大きさを変える
4. 完成プレビューに切り替える。**タイトル、本文の行、シール、画像の位置**が変わっていないこと
5. 編集に戻り、書き足してもう一度プレビューへ。位置の変化を確認する
6. 次へ渡す→確認→完成した日記を開き、プレビューと配置が一致すること

## 文字とデフォルト設定
1. 設定画面で「よもぎ」＋青色＋23pt＋中央寄せ＋さくら用紙を選ぶ
2. 新しい日記を開くと自動で反映されること。編集中の変更項目は折りたたまれていること
3. 「このページだけ文字を変更」でクレー・グリーンに変える
4. 保存して閉じる→再び開くとページ固有の設定が復元されること
5. 設定画面を別のフォントに変えても既存の下書きと完成ページは変わらないこと
6. 新しい日記だけ設定画面のデフォルトが使われること

## 長文、下書き、操作
1. 500〜2,000字の本文と3行のタイトルを入力し、プレビューで末尾が切れないこと
2. フォントサイズを14ptと30ptで切り替えて文字とシールの位置を確認
3. カメラロールから写真を「1枚添える」→閉じる→再開して残っていること
4. シール長押しで「向きと大きさを戻す」を試す
5. シールだけ削除したとき写真が残り、写真だけ削除したときシールが残ること
6. 送信時に確認画面が出ること

## 共有日記
Firebase設定・デプロイが完了している場合のみ:
- 別iPhoneから作成した日記帳へ参加し、ページを回す
- 完成ページで選択したフォントとシールの場所が表示されること
- 幅の異なる端末で本文の改行が変わる場合は、シールが**文字の同一字形の上に固定される保証はない**ことに留意

## 既知の制約
- v0.6以前に渡したページのシール位置は推測できないため、自動位置補正しません
- 現在のシールは**用紙全体の相対座標**です。長文を後から書き足してノートの高さが変わった場合、配置が見た目上移動することがあります。書き終えてからシールの位置を調整してください
- スクリーン幅が異なるiPhoneでは改行幅が変わり、特定の文字に対するシールの位置が変わることがあります
- Cloud Storageの本人確認/プライバシー統合テスト、Firebase本番設定、実機UI自動テストは別途必要
